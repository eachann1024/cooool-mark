# Third-party notices

Cooool Mark is built on top of the following open-source projects:

## MyGo

- Repository: https://github.com/egoist/mygo
- Usage: Native cross-platform desktop UI, windowing, tray, and packaging toolchain.

## Purego

- Repository: https://github.com/ebitengine/purego
- License: Apache License 2.0
- Usage: Pure-Go foreign function bindings without CGO.

## go-pinyin

- Repository: https://github.com/mozillazg/go-pinyin
- License: MIT License
- Usage: Chinese Pinyin and initials search matching for bookmarks.

## golang.org/x/net

- Repository: https://cs.opensource.google/go/x/net
- License: BSD-3-Clause License
- Usage: HTML metadata and icon parsing when fetching bookmark pages.
